# Help & support

INGLORIOUS Advanced is an independent project for supported Glorious keyboards. It is not affiliated with Glorious.

## Find help

| What you need | Where to go |
| --- | --- |
| Install the app, set up a keyboard or restore original firmware | [Setup & recovery guide](docs/getting-started.md) |
| Check an exact model, layout or revision | [Supported keyboards](docs/model-support.md) |
| Get the latest version | [Downloads](https://github.com/LatroX-dev/INGLORIOUS-Advanced/releases/latest) and [Changelog](CHANGELOG.md) |
| Report a problem, suggest a feature or share a hardware result | [Choose an issue template](https://github.com/LatroX-dev/INGLORIOUS-Advanced/issues/new/choose) |
| Ask a question by email | [inglorious@latrox.dev](mailto:inglorious@latrox.dev) |
| Report a security vulnerability | [Security reporting](SECURITY.md) |

The **?** button in the app opens the guide in your selected language. **Device → Feedback & contact** prepares a report for you to review before sharing.

## Report a problem

Include the exact keyboard model and layout, operating system, app and firmware versions, what you expected and what happened. A short error message or screenshot usually helps. Check [existing issues](https://github.com/LatroX-dev/INGLORIOUS-Advanced/issues) before opening a new one.

For a failed firmware operation, include the message shown by the app and whether the keyboard is still in update mode. Follow the displayed recovery instructions; do not force another model's firmware onto the device.

GitHub issues are public. Do not upload original-firmware backups, personal profiles, serial numbers or unredacted logs. Keep your backups locally for recovery.

## Share a hardware result

Working setups are useful feedback too. Use the hardware feedback template or **Device → Feedback & contact** and describe what you actually tested. A result for one layout or revision does not establish support for other variants.

## Help the project

Testing, translations, documentation and code contributions are welcome. See [Contributing](CONTRIBUTING.md) and the [Code of conduct](CODE_OF_CONDUCT.md). You can also [support development on Ko-fi](https://ko-fi.com/latrox); donations are optional and do not purchase priority support.
