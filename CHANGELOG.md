# Changelog

## 0.6.65

- Adjust keyboard brightness with the knob or assigned keys, even with the app closed.
- Choose knob presets, adjust their sensitivity and hold the knob to switch between selected functions.
- Drag to reorder knob functions and set short-press actions for each function directly in presets.
- Check the active knob function in its tooltip and get a brief light signal when switching.
- Fixed flickering knob controls and repeated status messages.
- Reload the keyboard configuration when opening the app or reconnecting a device, while keeping unsaved edits.
- Clearer editing panels with fewer controls shown at once.
- Test keys directly in the keyboard view on every model, including the Numpad.
- More compact firmware setup and update steps.
- Optional feedback reminders for experimental keyboards, with more useful problem reports.

## 0.6.57

- Fixed key labels and favorite-color help staying in German when using another app language.
- Added a Numpad typing test after setup and firmware updates, and on the Device page.
- The key list now scrolls to the selected key automatically.

## 0.6.55

- Added GMMK 3 PRO 100% ISO wired, non-HE support, including original-firmware recovery.
- New key, knob and individual LED test for the GMMK 3 PRO 100% ISO.
- Import saved CORE colors and simple key bindings into a profile copy.
- Optional device feedback and email contact.
- Set up connected supported keyboards directly from the device list.
- Clearer device tools and test buttons after firmware installation and updates.
- Fixed lighting tests being blocked when no key is pressed.
- New installations use red lighting when no saved colors are available.

## 0.6.51

- Fixed the app not opening after completing Windows setup.

## 0.6.50

- Turn off global lighting effects while keeping individual effects.
- Clearer lighting controls and a full-width Device page.
- Easier layer and Fn key setup.
- Fixed the app sometimes failing to reopen on Linux.
- Import and export key bindings for selected layers, including assigned macros.
- Removed repeated messages during firmware installation, updates and recovery.

## 0.6.49

- Clearer uninstall confirmation.
- Consistent Windows installer names, including win-x64.

## 0.6.48

- Updated security components.
- Improved firmware update reliability on macOS and Linux.
- Better protection against conflicting firmware operations.
- Safer profile and macro import/export.
- Fixed reactive lighting after long periods without input.

## 0.6.47

- First public release for configuring Glorious keyboards.
- Per-key lighting, effects, key bindings, macros, profiles and layers.
- Guided firmware installation, updates and original-firmware recovery.
- Windows installer with optional background start and a choice to keep personal data when uninstalling.
- Software update notifications and downloads.
- Early Alpha packages for macOS and Linux, with improved macOS packaging.

This changelog covers the app. The firmware update dialog shows changes for the connected device and its installed version.
